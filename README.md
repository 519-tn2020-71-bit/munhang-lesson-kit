# 문항 수업 하네스 (공유판)

> **AI에게**: 선생님이 이 폴더(또는 `guide/munhang-guide.md`)와 모의고사 시험지·해설지를 주면 `guide/munhang-guide.md` 합본 지침 하나를 읽고 그대로 따른다. 만들기 전에 인터뷰하고 설계표를 확인받은 뒤 세트 데이터 파일(.mjs)을 만든다.

모의고사·수능 국어 **시험지와 해설지**(PDF, HWPX)를 AI에게 주면 문항 풀이 수업용 HTML 파일이 나옵니다. 화면 넘기기·판서·반별 저장은 [exploragram](https://github.com/N-lifescience/exploragram) 엔진이 맡고, 이 폴더의 `munhang.js`가 문항 수업 부품을 더합니다.

이 공유판에는 **실시간 수업 기능(학생 기기가 교사 화면을 따라오고 답이 모이는 기능)이 없습니다.** 전자칠판이나 학생 기기 없이 TV·빔프로젝터·노트북으로 수업하는 교실을 생각한 판입니다. 수업 파일은 외부 서버에 아무것도 보내지 않습니다.

## 예시 먼저 보기

| 파일 | 내용 |
|---|---|
| `examples/모의고사예시/2026-10_10-13_드론자세제어.html` | **실제 모의고사 분석 예시.** 2026학년도 10월 고3 전국연합학력평가 국어 10~13번(드론의 자세 제어 시스템). 형광·주석, 전체 구조, 어휘, 구조도, 익스플로라그램 2장(P·I 제어, 상보 필터), 문항별 고르기·판정·정리까지 33장 |
| `examples/모의고사예시/2026-10_10-13_드론자세제어.mjs` | 위 수업의 세트 데이터. AI가 실제로 쓰는 것은 이 파일이다 |
| `examples/국어예시_도서분류법.html` · `skills/munhang/assets/set-example.mjs` | 직접 쓴 짧은 지문으로 만든 작은 예시(구조를 익히기 좋음) |

- 예시 HTML은 엔진과 부품을 인터넷(jsDelivr)에서 불러오는 가벼운 파일이라 **열 때 인터넷이 필요**합니다. 받아서 더블클릭하면 됩니다.
- 인터넷 없이 쓰는 한 파일이 필요하면 `node skills/munhang/scripts/gen.mjs examples/모의고사예시/2026-10_10-13_드론자세제어.mjs`로 직접 만듭니다(엔진까지 파일 안에, 실시간 없음).
- 모의고사 예시의 지문과 문항의 저작권은 출제 기관에 있습니다. 수업 참고용으로만 쓰고, 지문·문항을 따로 떼어 다시 배포하지 마세요.

## 수업 파일에 들어가는 장면

표지 → 독해 포인트 → ① 지문 분석(문단별, 형광과 파란 주석을 →로 하나씩) → ② 전체 구조 → ③ 어휘·핵심 개념·배경지식 → ④ 만점 구조도 → ⑤ 문항마다 세 장

- **고르기**: 발문과 선지. 반이 손을 들거나 말로 답을 정한 뒤 눌러 정답과 선지별 까닭을 봅니다.
- **선지 판정**: 선지를 →로 하나씩 꺼내고, 반의 예상을 ○✕로 고른 뒤 「판정과 근거」를 누르면 판정과 해설이 나오고 지문의 근거 구절에 형광이 칠해집니다.
- **정리**: 선지마다 근거 한 줄 → 적절/부적절, 정답 표시.

## 디자인(양식)

- **기본은 국어 예시 양식**입니다: 노란 테, 흰 카드, 테두리 제목 상자, 회색 지문 상자, 파란 기울임 주석, 다섯 색 형광.
- **학교나 선생님의 PPT 양식을 쓰고 싶으면** AI에게 PPT 파일이나 장 화면 캡처를 한두 장 올려 주세요. AI가 바깥 테 색, 글자 색, 강조 색, 제목 상자, 글꼴을 읽어 세트의 `style`에 넣고, 표지와 지문 장 하나를 먼저 보여 줍니다. 직접 바꿀 때는 세트 파일에서:
  ```js
  style: { bg: '#DCE8F5', ink: '#222222', note: '#1D4E89', line: '#9DB4CF', title: '#1D4E89', font: '나눔고딕' },
  ```
  (bg 바깥 테 · ink 글자 · note 주석·강조 · line 지문 상자 테두리 · title 제목 상자 테두리 · font 글꼴)

## 수업 파일 쓰는 법

1. 받은 HTML 파일을 **더블클릭**합니다(크롬이나 엣지). 파일 하나에 다 들어 있어 폴더가 따로 필요 없고, USB·메신저·메일로 보내도 같게 열립니다.
2. 넘기기: 키보드 → ←, 툴바의 「이전」「다음」, **폰·태블릿에서는 화면을 좌우로 밀기**(장 바깥 검은 여백에서 밀어도 넘어갑니다. 두 손가락 확대는 그대로).
   - 장 안에 숨은 단계(주석, 선지)가 남아 있으면 → 한 번에 하나씩 열리고, 다 열린 뒤 다음 장으로 갑니다.
3. 툴바: 손·펜·형광펜·지우개·레이저·되돌리기, 편집(글자 고치기), **타이머**(떠 있는 창, 처음 시간 = 세트 권장 시간), 목차, 전체 화면.
4. 판서는 반마다 그 컴퓨터의 브라우저에 저장됩니다.
5. 오른쪽 위에 빨간 「문항 점검 N」이 뜨면 눌러서 「AI에게 보낼 말 복사」 내용을 AI에게 붙여 고치게 합니다.

## 만들기

수업 파일은 **세트 데이터 한 파일**(`.mjs`: 지문·주석·문항만 적은 짧은 파일)을 `gen.mjs`가 HTML로 바꾸는 방식입니다. AI가 HTML 전체를 쓰지 않으니 토큰(비용)이 적게 들고, 양식이 늘 같고, 고칠 때도 그 줄만 고치면 됩니다. 꼴은 `skills/munhang/assets/set-example.mjs`를 보세요.

[Node.js](https://nodejs.org) 22 이상이 있으면, 이 폴더에서:

```
node skills/munhang/scripts/gen.mjs 세트.mjs --out 수업폴더
```

국어 예시 만들어 보기:

```
node skills/munhang/scripts/gen.mjs skills/munhang/assets/set-example.mjs --out examples
```

- 만들자마자 한 파일로 묶습니다(munhang·kit 파일, 엔진, 그림까지 안에 넣음, 실시간 없음).
- 처음 한 번은 인터넷으로 엔진을 받아 `skills/munhang/engine/vendor/`에 둡니다. 다음부터는 인터넷 없이 됩니다.

### 가) 채팅 AI(ChatGPT·Gemini·Claude 채팅)로

1. `guide/munhang-guide.md`, 시험지, 해설지를 함께 올리고 이렇게 씁니다.
   > 이 지침대로 18~21번 문항 수업 세트 파일을 만들어 줘.
2. AI가 묻는 것(범위, 장면, 주석 자료, 양식)에 답하고 설계표를 확인합니다.
3. 받은 세트 파일(.mjs)을 저장하고 위의 `gen.mjs` 명령을 돌립니다.
4. Node.js를 설치할 수 없으면 "HTML로 직접 만들어 줘"라고 합니다. 이때는 받은 HTML 옆에 `munhang` 폴더를 만들어 `skills/munhang/engine/`의 파일 다섯 개(munhang.css, munhang.js, kit.css, kit.js, ppt.css)를 넣어야 하고, 열 때 인터넷이 필요합니다.

### 나) Claude Code로

1. `skills/munhang` 폴더를 `내 사용자 폴더/.claude/skills/munhang`에 복사합니다.
2. (선택) 내용 검토 에이전트: `agents/munhang-content-reviewer.md`를 `내 사용자 폴더/.claude/agents/`에 복사합니다.
3. 시험지·해설지를 작업 폴더에 두고 "18~21번 문항 수업 만들어줘"라고 씁니다.

## 시험지 그림

〈보기〉·지문·선지에 그림·표·도표가 있으면 글로 바꾸지 않고 시험지에서 잘라 넣습니다(`pdfcrop.html`, `pngsink.mjs`). 결과 폴더의 `그림/`에 두면 묶을 때 파일 안에 들어갑니다. 그림이 제대로 들어갔는지는 세 겹으로 봅니다.

1. 묶기: 그림 파일을 못 찾으면 멈춥니다.
2. 파일을 열면 자동 점검: 열리지 않는 그림, 외부 주소 그림, 설명(alt) 없는 그림을 「문항 점검 N」에 띄웁니다. 화면 점검(`Munhang.layout()`)은 카드 밖으로 잘린 그림, 옆 글을 덮는 그림, 너무 늘어나 흐린 그림을 잡습니다.
3. 눈으로 대 보기: `Munhang.figures()` 그림 목록을 보고 그림이 든 장을 시험지 그 쪽과 나란히 봅니다(빠진 그림, 다른 자리, 윗줄 글자·테두리가 낀 것). 코드를 못 돌리는 채팅 AI는 이 목록을 전달 메모에 적어 선생님께 확인을 부탁합니다.

## 시험지 파일

- PDF: 그대로 올립니다. 범위에 해당하는 쪽만 잘라 올리면 토큰이 크게 줄어듭니다.
- HWPX: `node skills/munhang/scripts/hwpx2txt.mjs 시험지.hwpx 시험지.txt`로 글을 뽑아 올리면 쪽 그림보다 훨씬 가볍습니다.
- 구형 HWP: 한글에서 PDF나 HWPX로 저장해 올립니다.

## 저작권과 나누기

- 모의고사·수능 지문과 문항은 평가원·교육청의 저작물입니다. 그것이 들어간 세트 파일과 수업 HTML은 **자기 수업에만** 쓰고 인터넷(블로그, 공개 저장소, 공개 드라이브)에 올리지 않습니다.
- 이 저장소에는 개인 설정과 키가 없습니다. 시험 지문은 `examples/모의고사예시/`의 분석 예시 한 세트에만 들어 있습니다(출처: 2026학년도 10월 고3 전국연합학력평가 국어).
- exploragram 엔진은 N-lifescience의 저작물입니다(수업에 쓰는 것은 자유, 엔진 코드를 고쳐 다시 배포하려면 제작자의 허락이 필요). 그래서 이 저장소에는 엔진 파일을 넣지 않았습니다. 예시 HTML은 엔진을 제작자의 배포 주소에서 불러오고, 한 파일로 만들 때는 각자 받습니다.
